# 🤖 Chatbot Frontend  
### React + Vite + Tailwind CSS + PWA

This is the frontend application for the FastAPI Chatbot project.  
The app is built using **React (Vite)** with **Tailwind CSS** and supports **Progressive Web App (PWA)** features such as offline caching, manifest icons, and installability.

---

## 🚀 Features

- ⚡ Built with **Vite** — fast development & optimized build  
- 🎨 Styled using **Tailwind CSS**  
- 📱 Fully responsive chat interface  
- 💬 Connects to FastAPI backend for chatbot responses  
- 🌐 API URL from `.env` (Vite environment variables)  
- 📦 PWA support (manifest + service worker)  
- 🔄 Auto-scroll chat  
- 🔥 Modern UI with clean components  

---

## Install package
npm install --legacy-peer-deps

## Run the project
npm run dev
